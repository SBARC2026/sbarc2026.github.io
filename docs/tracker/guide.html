SBARC Site Tracker · how to sign in

1. Get on the team (once)

  1. Make a free account at github.com if you don't have one.
  2. Send your GitHub username to the project manager.
  3. You will get an email invitation to SBARC2026/sbarc-site-data. Open it and press Accept invitation.

2. Make your access key (once, about 1 minute)

  1. On GitHub open Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Token name: SBARC tracker. Expiration: the longest allowed (for example 1 year).
  3. Resource owner: choose SBARC2026.
  4. Repository access: Only select repositories → sbarc-site-data.
  5. Permissions → Repository permissions → Contents: Read and write. Leave everything else as it is.
  6. Press Generate token and copy it (it starts with github_pat_). GitHub shows it only once.
  7. If GitHub says the token is pending approval, tell the project manager: they approve it once.

3. Sign in and install

  1. Open sbarc2026.github.io/tracker on your phone, paste the key and press Sign in.
  2. Install it: on iPhone, Safari → Share → Add to Home Screen; on Android, Chrome menu → Install app.
  3. Keep the key private, like a password. If your phone is lost, delete the token on GitHub and make a new one.

Every day

  1. Pick the villa, building or external item.
  2. Type today's total % complete for the activities that moved (not the daily increase).
  3. Add manpower, blockers and a photo if you have them, then Send report. No signal? It saves on the phone and sends later.
